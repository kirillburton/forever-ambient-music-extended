Forever Ambient Music Extended

Music from modern WoW

An optional add-on for FAME: zone music from every era of the game, mixed into WoW: Forever.

Your own copyThe music is Blizzard's, so FAME can't ship it. A small script puts it on your computer.
Straight from BlizzardCopied from your retail game if you have it, otherwise from Blizzard's servers. Every file is checked.
Easy to removeIt goes into its own addon folder. Delete the folder and it's gone.

Install

Windows

  1. Open PowerShell: press Start, type PowerShell, press Enter.
  2. Paste this line and press Enter: 
    curl.exe -fsSLO https://kirillburton.github.io/forever-ambient-music-extended/import/import-retail.ps1; powershell -ExecutionPolicy Bypass -File import-retail.ps1
  3. Type the numbers of the expansions you want, or all, and press Enter.
  4. Restart WoW: Forever.

If it says it can't write into the game folder, open PowerShell with Run as administrator and paste the line again. -ExecutionPolicy Bypass only lets this one script run; no setting changes.

Mac

  1. Open Terminal (Applications → Utilities).
  2. Paste this line and press Return: 
    curl -fsSLO https://kirillburton.github.io/forever-ambient-music-extended/import/import-retail.sh && bash import-retail.sh
  3. Type the numbers of the expansions you want, or all, and press Return.
  4. Restart WoW: Forever.

Linux & Steam Deck

  1. On a Steam Deck, switch to Desktop Mode (Steam → Power → Switch to Desktop), open this page there, and open Konsole. Elsewhere, open a terminal.
  2. Paste this line (right-click → Paste) and press Enter: 
    curl -fsSLO https://kirillburton.github.io/forever-ambient-music-extended/import/import-retail.sh && bash import-retail.sh
  3. Type the numbers of the expansions you want, or all, and press Enter.
  4. Restart WoW: Forever (on the Deck, back in Gaming Mode).

It finds the game in Steam's Proton folders (SD card included), Lutris, Bottles or Wine. Run it as yourself, not with sudo.

Restart the game rather than typing /reload: the game only notices new addon files when it starts.

What you get

Pick any mix when the script asks. FAME plays each track only in zones it suits, so the music stays in character wherever you are.

Questions

Can I add or remove expansions later?

Yes: run the same line again and choose differently. Tracks you already have are skipped, and it offers to remove the ones you didn't choose this time. A stopped import carries on where it left off.

How long does it take?

With the retail game installed, a few minutes: the music is copied from it. Without it, everything is downloaded: all of it is about 6 GB, roughly 10–20 minutes on a typical connection.

It can't find my game

Add --wow and the path to your World of Warcraft folder to the end of the line, for example --wow "D:\Games\World of Warcraft". To find the folder: in the Battle.net app, click the gear next to Play, then Show in Explorer (Windows) or Show in Finder (Mac). On Linux it's inside the Wine or Proton folder Battle.net runs in, e.g. ~/.local/share/Steam/steamapps/compatdata/<number>/pfx.

Can I skip the questions?

Add options to the end of the line: --eras cata,mop or --all to choose expansions, --yes to answer yes, --local-only to never download, --cdn-only to ignore an installed retail game.

How do I remove it?

Delete the folder ForeverAmbientMusicExtended_RetailPack in World of Warcraft/_forever_/Interface/AddOns. Updating or removing FAME never touches it.

Can I read the script first?

Of course: import-retail.ps1 for Windows, import-retail.sh for Mac and Linux. They're plain text and use only what your system already has. Nothing is sent anywhere.

Something failed

Run the same line again: it always fetches the latest script and track list, and retries what failed. If a track still fails, Blizzard has probably moved it; please open an issue with what the script printed.
