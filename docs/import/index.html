Music from modern WoW for FAME

An optional add-on for Forever Ambient Music Extended: over 3,000 zone music tracks from every era of the game, added to WoW: Forever's rotation.

FAME can't ship this music: it belongs to Blizzard. Instead, a small script puts it on your own computer. It copies each track from your installed retail game if you have one, and otherwise downloads it from Blizzard's own servers, the same ones the Battle.net app uses. Every file is checked against Blizzard's checksum. Nothing is hosted here or sent anywhere.

The music goes into its own addon folder, ForeverAmbientMusicExtended_RetailPack, next to FAME. Updating FAME never touches it, and deleting that folder removes it all.

What you can add

Pick any of these when the script asks. All of it is music the game itself plays as open-world zone music; dungeon, raid, combat and cutscene music is left out.

On a Mac

  1. Quit World of Warcraft (or just restart it at the end).
  2. Open Terminal (in Applications → Utilities).
  3. Paste this and press Return. It downloads the script into your home folder and runs it: 
    curl -fsSLO https://kirillburton.github.io/forever-ambient-music-extended/import/import-retail.sh && bash import-retail.sh
  4. Type the numbers of the expansions you want (or all) and press Return.
  5. Start WoW: Forever. FAME picks the music up by itself.

Prefer to download it yourself? import-retail.sh, then run bash ~/Downloads/import-retail.sh. It's plain text, so you can read it first. It needs nothing macOS doesn't already have.

Good to know

  • Run it again any time to add or remove expansions. Tracks you already have are skipped, and a stopped import carries on where it left off.
  • Retail installed? Then nothing is downloaded except what's missing from it. Not installed? Everything comes from Blizzard's servers; about 6 GB takes 10–20 minutes on a typical connection.
  • WoW installed somewhere else? Tell the script where: bash import-retail.sh --wow "/path/to/World of Warcraft"
  • No questions: --eras cata,mop or --all. Use --local-only to never download, --cdn-only to ignore an installed retail game.
  • A /reload isn't enough after importing: the game only finds new addon files when it starts.
  • To remove it all, delete _forever_/Interface/AddOns/ForeverAmbientMusicExtended_RetailPack.

If something fails

Download the script again with the command above: it fetches the current track list every time it runs, and this page always has the latest version. When Blizzard patches the game, some tracks can move; the list here is updated to follow. If a track still fails, please open an issue with what the script printed.
